# Анализ банковских операций

## Описание
Приложение для анализа банковских транзакций, которое агрегирует данные о тратах, рассчитывает финансовые показатели и формирует отчеты на основе пользовательских настроек.

## Основные возможности

- **Сводка по операциям**: Анализ транзакций за заданный период (сводка по картам, топ самых крупных трат).
- **Курсы валют и акции**: Получение актуальных курсов валют и цен на акции, указанных в пользовательских настройках (`user_settings.json`).
- **"Инвесткопилка"**: Расчет суммы, которую удалось бы отложить, если бы каждая трата округлялась до заданного лимита (функция `investment_bank`).
- **Фильтрация по категориям**: Выборка трат по заданной категории за последние 3 месяца от указанной даты.
- **Экспорт отчетов**: Декоратор для автоматического сохранения результатов обработки (pandas DataFrame) в Excel-файл с временной меткой.


## Требования
- Python 3.14+
- Poetry (менеджер зависимостей)

## Зависимости
+ ### Основные
  * **Python** 3.14+
  * **pandas** >= 3.0.6 (Библиотека для обработки и анализа данных.)
  * **openpyxl** >= 3.1.5 (Библиотека для работы с Excel-файлами)
  * **requests** >= 2.34.2 (Библиотека для выполнения HTTP-запросов к внешним API)
  * **python-dotenv** >= 1.2.4 (Библиотека для загрузки переменных окружения из `.env` файла.)
  * **python-dateutil** >= 4.0.0 (Расширение модуля datetime для работы с датами и временем.)
  
+ ### Инструменты разработки
  * **flake8** >=7.5.0 (Проверка кода на соответствие стилю написания, который использует PEP 8 в качестве руководства.)
  * **black** >=26.10.1 (Автоматическое форматирование кода.)
  * **isort** >=9.0.2 (Сортировка импортов в коде.)
  * **pytest** >=9.1.1 (Фреймворк для написания и запуска тестов.)
  * **pytest-cov** >=7.1.0 (Плагин для проверки покрытия кода тестами.)

## Установка:
1. Клонируйте репозиторий:
```
git clone https://github.com/olgach-cmd/Project1.git
cd Project1
```
2. Установите зависимости:
```
poetry install
```

## Тестирование:

**Запуск всех тестов:**
```
poetry run pytest
```
**Запуск тестов с выводом процента покрытия кода в терминал:**
```
poetry run pytest --cov=src
```
**Генерация подробного HTML-отчета о покрытии:**
```
poetry run pytest --cov=src --cov-report=html
```
После выполнения этой команды в корне проекта обновится папка *htmlcov*. 
Чтобы просмотреть детальный отчет о том, какие строки кода покрыты тестами (подсвечены зеленым), 
а какие нет (подсвечены красным), откройте файл *htmlcov/index.html* в любом браузере.
